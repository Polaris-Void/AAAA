# Changelog

All notable changes to Polaris-Kit-Pro are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and the project adheres to [Semantic Versioning](https://semver.org/).

## [3.1.1] — Zero-Temp Execution (Defender false-positive fix)

Windows Defender (and similar heuristics engines) flagged the launcher
because — like every dropper — it wrote an embedded script into `%TEMP%`
and then executed it. This release removes that pattern from the design
entirely.

### Changed
- **On-disk payload execution.** The launcher now runs every tool script
  **in place** from the `payloads\` folder that ships next to the
  executable — the same auditable files the repository ships. Nothing is
  ever written to `%TEMP%` for execution, so the
  write-script-then-execute dropper signature cannot occur by
  construction. The per-run staging machinery (`run-<pid>-<random>`
  folders) is retired; stale folders from older releases are still
  purged at boot, and the private temp folder now only backs the child
  processes' own TEMP/TMP environment.
- **Argument-passed targets.** Folder-dependent tools (image/video
  renamers, USB immunizer, unpacker) receive the target folder as
  argument 1 — the `%~dp0` script-patching (which required patched
  copies per run) is gone. Standalone use of the scripts is preserved:
  with no argument they still operate on their own folder.
- **Pin table instead of embedded bytes.** `src/payloads.rs` is now a
  small sha256 pin table (resid → file → digest) regenerated by
  `tools/gen_payloads.py`; the ~160 KB of embedded byte arrays are gone.
  The pin of the selected payload is verified against the on-disk file
  right before every dispatch, and the boot audit verifies the whole
  folder — a modified or missing file refuses to run with a clean,
  explicit message.
- **Fuller version resource.** The executable now also carries
  `CompanyName`, `FileVersion` and `ProductVersion`, so file-reputation
  heuristics see a complete, honest binary identity.

### Fixed
- Target folders containing `!` are now rejected by the folder gate —
  the character corrupts delayed-expansion values inside the
  folder-dependent batch tools.

### Notes
- Keep `payloads\` next to `Polaris-Kit-Pro.exe` (the build scripts copy
  it into `dist\` automatically). Without the folder the UI still starts,
  but every tool aborts with a clear message instead of degrading into a
  temp-dropping fallback.
- If your antivirus quarantined v3.1.0, restore/allow the folder and run
  this build — the flagged behavior no longer exists.

## [3.1.0] — Defender-Clean Execution & Live Progress

A security-first refactor of how the launcher executes its modules, plus
the three most-requested UX upgrades: live progress bars, a universal log
panel, and grid/list dashboard views.

### Added
- **Live 0–100 % progress bars.** Triggering an action mounts a sleek
  linear progress bar directly underneath the clicked button. Determinate
  percentages are parsed live from the tool's own output stream (DISM,
  Robocopy, explicit `[PROGRESS] n` markers); silent tools get a polished
  indeterminate glide. Elapsed seconds are shown alongside.
- **STOP / CANCEL on every running action.** A red «توقف عملیات» button
  sits next to the progress bar and in the log panel; it terminates the
  entire child process tree instantly (Job Object first,
  `taskkill /PID <pid> /T /F` as the hardened fallback) and logs the
  cancellation.
- **Universal LOG slide-over.** The LOG button moved into the header bar
  (immediately left of the language switcher) and opens a non-blocking
  slide-over panel from every view and sub-page — dashboard, any tool
  page, even while a task runs. <kbd>Ctrl</kbd>+<kbd>L</kbd> toggles,
  <kbd>Esc</kbd> closes. The log text itself is English-only by design so
  `[ OK ]`/`[ERROR]` markers stay greppable, and the panel header reads
  simply "LOG".
- **Grid & list dashboard views.** The toggle ([GRID | LIST] /
  «شبکه | فهرست») sits in the toolbar's control cluster next to the
  search and sort controls; the list view is a compact structured table
  (ID badge, title, category chip, one-line brief, GitHub link, OPEN).
  The choice persists in `settings.ini`; grid remains the default, and
  the app always starts in English unless the user switches.
- **Defender-clean payload vault.** Every self-elevation block was
  removed from the embedded scripts (`powershell Start-Process -Verb
  RunAs` in 11 payloads, a VBS `getadmin.vbs` dropper in the USB tool) —
  the launcher already elevates once via UAC, so payloads now merely
  guard and fail clean. Interactive waits (`pause`, `timeout` countdowns,
  the 10-second PowerShell countdown in the user-backup tools) are gone;
  every script ends with an explicit, meaningful exit code.
- **Clean PowerShell dispatch.** The four tools that used long inline
  `-Command` one-liners (Display Driver Backup, DNS + Proxy Reset,
  Directory Tree Exporter, SHA-256 Tree Auditor) now ship as real `.ps1`
  payloads executed strictly as
  `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <staged>` —
  never `-EncodedCommand`, never base64, no unquoted paths.
- **Auditable `payloads/` directory + `tools/gen_payloads.py`.** The
  module scripts now live as readable files in the repository; the
  embedded vault (with its SHA-256 pins) is regenerated from them.
- Regression tests for the vendor-list sentence from the bug reports
  (`(مثل AMD، NVIDIA و Intel)`), the NCSI blurb and registry-value table
  cells — locking the bidi engine's correct phrase isolation in CI.

### Changed
- **Toolbar restructure.** The control cluster is now
  [GRID|LIST] [SEARCH] [SORT]: the search bar took the slot previously
  occupied by the sort switch, and the sort/alphabet buttons moved to the
  right-hand side adjacent to the search. The language switcher and LOG
  button moved to the header. In Persian the entire row mirrors.
- **Header chrome.** Window controls got Fluent-style spacing — the
  close button no longer jams against the window border — and the
  language switcher is a black button next to minimize.
- **Tool sub-header.** Exactly ONE GitHub button per tool page now (the
  redundant bottom-row button is gone), with the EN/FA readme toggle on
  its left. Action buttons keep their English labels in both languages.
- **Action layout.** The two primary contrasting actions sit side-by-side
  in a 2-column grid; further actions get their own centered full-width
  rows — identical heights, symmetric margins everywhere (fixes the
  skewed NCSI button row).
- **Scrollbar.** Sleek dark translucent thumb (expands on hover) with a
  permanently reserved thin gutter so it can never cut into the cards;
  horizontal overflow is impossible by construction.
- **Brand mark.** The white corners around the lion tile are removed —
  the artwork fills the whole logo frame with transparent corners, in the
  title bar and in the rebuilt multi-size `icon.ico`.

### Removed
- **VIEW VAULT everywhere.** The button and its modal (which could lock
  the UI) are eradicated from the codebase: actions, dialog, scanner
  thread and the `arboard` clipboard dependency are all gone.

## [3.0.0] — Vazirmatn One-Family Refresh

A complete typographic and bidirectional-text overhaul of the NATIVE-1080
interface, plus a redesigned toolbar and window chrome.

### Added
- **In-app Unicode-bidi engine** (`src/bidi.rs`). egui 0.36 has no bidi
  algorithm, so mixed Persian/Latin lines used to come out with reversed
  words (`NLA` -> `ALN`) and Persian sentences with reversed word order.
  The engine resolves per-character directions (UAX #9 N1/N2), groups
  tokens into same-direction phrases, lays phrases out visually and wraps
  lines itself — Persian digits, brackets, quoted Latin phrases and
  comma-separated Latin lists all render correctly now, and RTL paragraphs
  are properly right-aligned with per-line padding.
- **One type family: Vazirmatn.** Every stack — English and Persian, body
  text and log console — is now Vazirmatn (Regular/Medium/SemiBold/Bold).
  Inter, Archivo and Geist Mono are retired, which also shrinks the EXE.
- **Titlebar lion mark.** The lion icon returns to the title bar at a
  correct 30px size with clean rounded corners, decoded once into a GPU
  texture.
- **Category section bar.** A labelled separator above the grid
  ("SYS — 1 TOOL" / «سیستم — ۱ ابزار») frames every category — including
  the single-tool ones such as SYS and AUDIT.
- **ACTIONS / TARGET / README section headers** with hairline separators
  on every tool page, giving single-action modules the same framed
  structure as the rest.

### Changed
- **Toolbar redesign.** One row: language switch at the far left, the nine
  category pills starting directly under the wordmark and flowing
  left-to-right in both languages, then search, the A–Z / 01–12 segmented
  sort switch and a compact LOG button at the far right.
- **Search field.** Soft-cornered well with a magnifier glyph, a focus
  ring, a language-aware placeholder and a vertically centered caret (the
  old caret floated at the top of the box).
- **Cards.** Larger 4-column cards with everything centered: accent badge,
  title, blurb, GitHub link and the OPEN button.
- **Window controls.** Smaller, rounded, painter-drawn glyphs (a crisp
  minus, square and cross) instead of font glyphs; the close button gets
  its classic red hover.
- **Log console.** Rows now start at the left edge as a proper LTR
  terminal (they used to render centered), with ellipsized long lines.
- **README_FA data.** The embedded Persian documentation was stored
  pre-shaped in visual order (a leftover from the Python era) and rendered
  mirrored by the new shaping stack; it is converted back to logical
  order with restored ZWNJ half-spaces.
- **Subtitle.** Now reads "Built for Windows 10 & 11 — best experienced on
  Windows 10 and 11" / «برای ویندوز ۱۰ و ۱۱ ساخته شده — بهترین تجربه در
  ویندوز ۱۰ و ۱۱».

### Fixed
- RTL header rows inside the detail scroll area consumed the full
  (unbounded) scroll height and pushed the page content off-screen; they
  now allocate an explicit row height.
- Persian digits ran reversed inside RTL runs (harfbuzz guesses the run
  direction from the first character's script); digit-led tokens are
  pre-reversed to cancel the guess.

## [3.0.0] — NATIVE-1080

The first GitHub-source release of the PRO edition, shipped with a full
interface refresh targeting a 1920×1080 desktop.

### Fixed
- **Window controls.** Minimize / Maximize / Close were pushed off-screen by an
  over-sized drag band; the band now reserves exactly the width the controls
  need, so all three buttons are always visible at the top-right edge.
- **Category tabs.** The nine category tabs rendered stacked vertically in the
  middle of the page; they are now a single horizontal row pinned to the far
  top-right corner, with search and sort on the same line.
- **Broken in-app images.** All in-app bitmap images (header mark, module
  icons) failed to load in release builds and rendered as warning triangles;
  they are removed entirely — the UI is now pure vector text and hairlines.
- **White corner fringe.** The Windows 11 1px system border drew a light rim
  around the rounded corners (most visible at the top); the border color is
  now set to `DWMWA_COLOR_NONE`, leaving clean rounded corners.
- **Lion mark keyline.** The window/taskbar lion no longer carries the white
  keyline ring around its rounded square.
- **RTL text alignment.** Persian card titles, blurbs and table rows are
  properly right-aligned instead of painted left.

### Changed
- **One language switch for everything.** The single green `FA/EN` button now
  translates the entire interface — tabs, cards, actions, dialogs, boot banner,
  vault listings and hints — except the product name. Persian titles were added
  for all 12 modules.
- **Cleaner header.** The in-app lion logo, the yellow `PRO` chip and the boxed
  brand frame are removed; the wordmark sits top-left with the GitHub link
  beside it and the "Made for Windows 10 and 11" tag inline.
- **Toolbar at the top-right.** Category tabs, search and the suite-order/A–Z
  sort share one 44px row; tab cells adapt their width so nothing overflows.
- **Footer removed.** The version/name repetition, VAULT/ELEVATED/1080P badges
  and the UI-scale chip are gone; content reaches the bottom edge. UI zoom
  stays available via `Ctrl + +/−/0` (persisted).
- **Module cards are icon-free** and text-align consistently; the OPEN button
  keeps its full-width anchored placement.
- **Bilingual vault inspector.** File listings, sizes and folder scans follow
  the active language (including byte-size units in Persian).

### Security
- Staging directories keep unpredictable per-run names and are sha256-verified
  before execution; stale directories are purged on boot (24h cutoff).
- Every tool runs inside a kill-on-close job object; STOP and window close
  terminate the entire process tree.
- `unsafe` remains denied crate-wide except in the single audited Win32 FFI
  module; release builds use LTO and stripped symbols.
